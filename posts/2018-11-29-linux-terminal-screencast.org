#+DESCRIPTION: Recording a Linux terminal session to GIF with asciinema

[[https://github.com/asciinema/asciinema][asciinema]] is a good, simple-to-use tool to record a screencast of a terminal session.

And [[https://github.com/asciinema/asciicast2gif][asciicast2gif]] converts the recording to a GIF animation.

Install asciinema:

#+begin_example
virtualenv -p python3 venv
source venv/bin/activate

pip install asciinema
#+end_example

Record a session:

#+begin_example
$ asciinema rec demo.cast
asciinema: recording asciicast to demo.cast
asciinema: press <ctrl-d> or type "exit" when you're done

...

$ <ctrl-d>
asciinema: recording finished
asciinema: asciicast saved to demo.cast
#+end_example

And convert it to GIF:

#+begin_example
docker run --rm -v $PWD:/data asciinema/asciicast2gif -t solarized-dark demo.cast demo.gif
#+end_example
