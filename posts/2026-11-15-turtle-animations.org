Some simple, but nice turtle graphics animations.

To restart animations, refresh the page.

The turtle here is a simple JavaScript version of python turtle module (see [[../static/turtle.js][turtle.js]]).

#+NAME: turtle-spiral
#+begin_src js
for (let i = 0; i < 1000; i++) {
  t.forward(i);
  t.right(70);
}
#+end_src

#+begin_export html
<canvas class="turtle" data-src="turtle-spiral" width="400" height="400"></canvas>
#+end_export
