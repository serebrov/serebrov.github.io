** Operators
:PROPERTIES:
:CUSTOM_ID: operators
:END:
=[operator]{motion}= - apply
[[https://vimhelp.org/motion.txt.html#operator][:h operator]] to
the text defined by motion.

For example: =>G= - shift everything until the end of file to the right (=>= -
shift right operator, =G= - end of file motion), =gg=G= - format the
whole file (gg - jump to the top, === - format operator, =G= - end of
file motion).

Operators:

- =c= - change
- =d= - delete
- =y= - yank into register (does not change the text)
- =J= - join lines, =gJ= - join lines without adding a space between
  them
- =~= - swap case (only if 'tildeop' is set)
- =g~= - swap case, visual mode =~=
- =gu= - make lowercase, visual mode =u=
- =gU= - make uppercase, visual mode =U=
- =!= - filter through an external program
- === - text indenting, using =equalprg= or internal function
- =gq= - text formatting, using =formatexpr= or =formatprg= or internal
  function
- =g?= - ROT13 encoding
- =>= - shift right (in visual mode =>=, in normal mode =>>=)
- =<= - shift left (in visual mode =<=, in normal mode =<<=)
- =zf= - define a fold
- =g@= - call function set with the 'operatorfunc' option

More info:
[[https://vimhelp.org/map.txt.html#%3Amap-operator][how to define your own operator, :h :map-operator]],
[[https://vimhelp.org/map.txt.html#omap-info][how to define your own motion, :h omap-info]].

** Motions
:PROPERTIES:
:CUSTOM_ID: motions
:END:
*** Horizontal (left-right) motions
:PROPERTIES:
:CUSTOM_ID: left-right-motions
:END:

Imagine we have the following line in the buffer where =*= is the cursor position:

#+begin_example

    Pudding—Alice: Alice—Pudding.
┆   ┆     ┆*┆            ┆      ┆  ┆
┆   ┆     ┆ ┆            ┆      ┆  ┆
0   ^     h l      gm    25|    g_ $
#+end_example

With =h= / =l= we can move one character left or right (it can
also take count, =5h= moves 5 characters to the left).

=0= jumps to line start and so on.
=^= jumps to the first non-space character (so the first =P=).
=g_= jumps to the last non-space and =$= to the end of the line (assuming that we
have some spaces at the end in the example above).

The =[count]|= moves to the specified column (25 in this case, which is the second =P=).

When the line is wrapped, =g^= moves to the start of the screen line. The
=gm= depends on the window width and moves to the center of the screen
line.

**** Jump to the character: =f= / =t=, =F= / =T=

=f= jumps forward to the character given after it, so =fc= jumps to the next =c=.

=t= jumps forward "till" the character (stops just before it).

=F= and =T= do the same backwards.

#+begin_example

    Pudding-Alice: Alice-Pudding.
     |    *    |        |
     Fu        fc       tP
     TP
#+end_example

*** Words and WORDs
:PROPERTIES:
:CUSTOM_ID: words-and-words
:END:

"Word"s are sequences of letters, digits and underscores (can be configured with ='iskeyword'=)
and "WORD"s are any non-blank characters.

We can use the following motions (the cursor is at the =*= position):

#+begin_example
Words and WORDs

    ┌┈┈┈┈┈┈┈┈┐ ┌┈┈┈┈┈┈┈┐ ┌┈┈┈┈┈┈┐ ┌┈┈┈┈┈┈┈┈┐ - WORDs
    ┌┈┈┈┈┈┐┌┈┐ ┌┈┈┈┐┌┈┈┐ ┌┈┈┈┐┌┈┐ ┌┈┈┈┈┈┐┌┈┐ - words
    Pudding--- Alice:::: Alice--- Pudding...
    ┆      ┆   *    ┆    ┆
    ┆      ┆        w    W ┈┈┈┈┈┈ next word / WORD
    ┆      ┆
    B      b - prev word / WORD

    Pudding--- Alice:::: Alice--- Pudding...
             ┆     ┆   ┆ *   ┆  ┆
             ┆     ┆   ┆     e  E ┈┈┈┈┈┈ end of the word / WORD
             ┆     ┆   ┆
             ┆     ┆   ge/gE ┈┈┈┈┈┈┈┈┈┈┈  end of the prev word / WORD
             ┆     ┆
             2gE   2ge ┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈  two words / WORDs back
#+end_example

*** Vertical (up-down) motions
:PROPERTIES:
:CUSTOM_ID: up-down-motions
:END:

Vertical motions (the cursor is at =*=):

#+begin_example
  Up-down motions ...                     ┈┈┈ gg
  ...
  But the Red Queen looked sulky,
  and growled                             ┈┈┈ k - line up, `-` - up and move to the start
  'Pudding—Alice: Alice—Pudding.     *
  Remove the pudding!'                    ┈┈┈ j - line down, `+` - down and move to the start

  and the waiters took it away so quickly ┈┈┈ :+3   - range is a motion, c:+2, d:107
  that Alice couldn't return its bow.     ┈┈┈ /bow  - search is a motion, c/bow
  ...
  ...                                     ┈┈┈ G
#+end_example

Note that =:= (which lets you run a command from the Vim command line) can be used
as a motion: =d:call search('f')= will delete until the next 'f' found by the
=search()= function.

There is also =[count]_= motion which moves =count-1= lines down and
jumps to the start of the line. It is like a =^= motion, but with count.
If there is no count or count=1 it moves to the current line start, with count > 1
moves down and jumps to the start.

The =[N]%= jumps to the N% of the file, =:[range]go[to] [count]= and
=[count]go= jump to the =count= byte in the file.

*** Text object motions / various motions
:PROPERTIES:
:CUSTOM_ID: text-object-motions-various-motions
:END:
#+begin_example
Matching pair () {} []      - % - move to the matching pair, make sure to enable the
              /**/            matchit.vim (standard plugin), ":h matchit.txt"
              <tag></tag>     "matching" things can be html tags, if/else statements
              if/else/endif   and you don't have to be at the pair item for % to work
              etc             for example, in "my text (something)", you can use % when
                              cursor is at the start of the line.

A next / prev sentence.     - ) / ( - [count] sentences, like y3) - yank 3 sentences

A paragraph of text.        - } / { - [count] paragraphs

Unmatched (                 - [( / ]( - prev/next unmatched (
Unmatched {                 - [{ / ]{ - prev/next unmatched {
Unmatched #if / #else       - [# / ]# - prev/next unmatched #if / #else

A method of the class       - [m / ]m, and [M / ]M move to the end of the method

A block comment /*  */      - [*, [/ / ]*, ]/ - prev / next comment mark

[n] lines from the top      - [n]H
[n] lines from the bottom   - [n]L
Middle line                 - M

A section                   - ]] / [[ - [count] sections, see ":h section",
                              can be redefined by filetype plugins, like move between
                              classes / methods in python.
End of the section          - ][ / [] - [count] end of section
#+end_example

Each of them can be used as an operator target.

For example =c%= - change until the matching pair:

#+begin_example
    if (x and y or something(b, c))
                   *
                   |
                   c%        - from here it will find the parens pair around "b, c"
                               and will jump to the end paren

    if (x and y or ▓)        - as a result, we are changing the whole "something(b, c)"
                               with just one motion

    link_to("text", my_p(sing("one"), plu(fn("two"))))
                      *   A                                B
                      |
                      c%   --- from here will change until B
                      %c%  --- will change the A-B, including brackets
                      %ci( --- here will change inside the A-B
#+end_example

See also [[https://thepugautomatic.com/2014/03/vims-life-changing-c-percent/][Vim's life-changing c%]].

*** Text object selection
:PROPERTIES:
:CUSTOM_ID: text-object-selection
:END:

Text objects allow specifying which part of the text we want to operate on.

There are usually "around" objects which include surrounding elements (such as "a(" includes
the surrounding parens) and "inner" objects which only include what's inside (such as "i("
that only selects text inside the parens).

A simple way to try text objects is to use them with the "v" (visual mode) motion.
For example, "vaw" will select the "around word" and "viw" will select the "inner word".

#+begin_example
 word, word_two          - aw / iw (regular / inner "word" text object)
 WORD, word--%4-         - aW / iW ("WORD" object)

 'string'                - a' / i'
 "string"                - a" / i"
 `string`                - a` / i`

 A sentence.             - as / is

 A paragraph of
 text. It also has a
 text object.            - ap / ip

 [ block ]               - a[, a] / i[, i]
 ( block )               - a(, a), ab / i(, i), ib
 < block >               - a<, a> / i<, i>
 { block }               - a{, a}, aB / i{, i}, iB
 <tag>value</tag>        - at / it
#+end_example

Plugins that add more text objects: [[https://github.com/wellle/targets.vim][wellle/targets.vim]], [[https://github.com/michaeljsmith/vim-indent-object][indent object]], [[https://github.com/coderifous/textobj-word-column.vim][column object]].

The quotes text objects (a', a", etc) look forward if the cursor is not
inside the quoted string. For example, if cursor is on the =*= position in
=text [*] text 'quote'=, the =ya'= will yank (copy) the quoted word. The
[[https://github.com/wellle/targets.vim][wellle/targets.vim]] makes other text objects also look forward (and then also backward
if there is no object forward).

Inner text objects (=iw=, =iB=, etc) do not include the surrounding
marks. For words this is trailing space, for blocks - brackets.

#+begin_example
"aw" vs "iw" vs "w"

    ┌┈┈┈┈┈┈┐   - yaw - yank word with trailing space - "Pudding "
    ┌┈┈┈┈┈┐    - yiw - yank only word - "Pudding"
    Pudding Alice
#+end_example

Note: motions like =yw= and =yaw= do the same and yank the word with the
trailing space (same for =daw=, =caw=, etc), but it will be a bit
different in visual mode. The =vaw= will also select the first letter of
the next word (because =w= actually moves to there). It works in a
similar way for other objects, like sentences. See also [[https://vimhelp.org/motion.txt.html#exclusive][:h exclusive]].

*** Motions and operators
:PROPERTIES:
:CUSTOM_ID: motions-and-operators
:END:
There are 3 types of the effects of operators: =characterwise=,
=linewise=, =blockwise=.

And =*wise= can be varied by operator and motion:

- =dw= - characterwise - delete a word
- =>j= - linewise - indent 2 lines
- =dj= - linewise - delete 2 lines

It is possible to force =*wise= with the following keys:

- =v= - characterwise
- =V= - linewise
- =<C-v>= - blockwise

Usage: ={operator}{*wise-specifier}{motion}=, see
[[https://vimhelp.org/motion.txt.html#o_v][:h o_v]]:

- =dvj= - characterwise
- =dVj= - linewise
- =d<C-v>j= - blockwise

See also:
[[https://web.archive.org/web/20101113085548/http://whileimautomaton.net/2008/11/vimm3/operator][operator, the true power of Vim]].

* Marks
:PROPERTIES:
:CUSTOM_ID: marks
:END:
[[https://vimhelp.org/motion.txt.html#mark-motions][:h mark-motions]].

- =a-z= - local marks (inside the buffer), reset when buffer is deleted
- =A-Z= - global (across files)
- =0-9= - automatically set from .viminfo, '0 - cursor position on last
  exit from Vim, '1 - previous exit, and so on, see
  [[https://vimhelp.org/starting.txt.html#viminfo-file-marks][:h viminfo-file-marks]]

Set the mark with =m{a-zA-Z}=.

Jump to the mark:

- ='{a-z} `{a-z}= - jump to mark in the current buffer, with ' - to the
  first non-blank char of the mark line, with ` - to the exact mark location
- ='{A-Z0-9} `{A-Z0-9}= - jump to mark in the file (may be another file,
  not a motion in this case)

Jump to the mark is a motion (can be used with operators).

List of marks - =:marks=.

Delete marks with =:delm=:

#+begin_example
:delm a - delete mark `a`
:delm a b or :delm ab - delete marks `a` and `b`
:delm p-z - delete all marks from `p` to `z`
:delm! - delete all marks for the current buffer (only a-z, not A-Z and 0-9)
#+end_example

* Normal mode - jump list and change list
:PROPERTIES:
:CUSTOM_ID: normal-mode---jump-list-and-change-list
:END:

Jump list is a very powerful way to navigate files in Vim. It is similar to the browser
back / forward navigation button. After you use a motion or a command like =gf= to open another
file, you can use =C-o= to go back and =C-i= to go forward again.

The change list lets you move across edits in a similar way.

** Jump list
:PROPERTIES:
:CUSTOM_ID: jump-list
:END:
- =<C-O>= / =<C-I>= - move back / forward in the
  [[https://vimhelp.org/motion.txt.html#jumplist][jump list]],
  =:jumps=
- =''= / =``= - jump to the previous place you jumped here from
- =gf= - open file under cursor
- =gd= / =gD= - local / global variable definition
- =C-]= - jump to the tag
- =C-^= - switch between two recent files
- =[num]<C-^>= - switch to 'num' file (see file numbers in :buffers)

** Change list
:PROPERTIES:
:CUSTOM_ID: change-list
:END:
- =g;= / =g,= - move back / forward the
  [[https://vimhelp.org/motion.txt.html#changelist][change list]],
  view the list =:changes=
- =gi= - jump to last edit and start the insert mode (uses ='^= mark)
- ='.= - jump to last edit position


** Special marks
:PROPERTIES:
:CUSTOM_ID: special-marks
:END:

Vim also provides a set of special marks that can be used to quickly jump around:

#+begin_example
'[ `[ / '] `]   - first / last char of last changed / yanked text
'< `<  / '> `>  - first / last char of last visual selected text
''  ``          - previous jump position
'" `"           - position before exiting the buffer (useful when you reopen it)
'^ `^           - last insert mode position
'. `.           - last edit position
[' [` / ]' ]`   - [count] previous / next lowercase mark
#+end_example

Some shortcuts that are useful in the command and insert mode:

- =<C-H>= - delete previous character

* Insert mode: editing shortcuts
:PROPERTIES:
:CUSTOM_ID: insert-mode-editing
:END:

And some editing shortcuts for the insert mode (everything can be done by switching
to normal mode, changing the text and switching back to insert, but it may be faster
to do a small edit operation while staying in the insert mode):

- =<C-T>= / =<C-D>= - indent / un-indent, useful for markdown lists
- =<C-Y>= / =<C-E>= - insert char above / below the cursor
- =<C-A>= / =<C-X>= (normal mode) - increment/decrement number under the cursor
- =g<C-A>= in visual mode - sequentially increment values in a column

#+begin_example
                  1                1                1
                  1 -- select --> |1| -- g<C-A> --> 2
                  1               |1|               3
#+end_example

This one is special as it does switch to the normal mode, but only for one command:
- =<C-O>= - execute normal command and get back to insert mode

[[https://vimhelp.org/insert.txt.html][:h insert.txt]]

* Insert and command mode: insert from the register
:PROPERTIES:
:CUSTOM_ID: insert-command-mode---insert-from-the-register
:END:

=<C-R><r>= inserts the text from the register.

Examples:

- =<C-R>0= (zero) - paste yanked text
- =<C-R>"= - paste the text from the unnamed register

If we have "Hello" in the =a= register and "World" in the =b=, we can
insert them like this: ="ap"bp= from normal mode.

But it is easy to do from the insert mode =<C-R>a<C-R>b= and change will
be repeatable with dot.

See also: [[file:2026-10-17-vim-ctrl-r-is-good.org][Vim: The useful Ctrl-R]]

* Insert mode: insert the last inserted text
:PROPERTIES:
:CUSTOM_ID: insert-mode---insert-the-last-text
:END:

=<C-A>= - Insert the last text added in the insert mode.

Example:

#+begin_example
"some_text(...)
ct(new_text"      - change "some_text" to "new_text" till the (

"some_text, ...   - now we need to do the same change, but till the comma
ct,<C-A>          - we enter the new command `ct,` and then use Ctrl-A to insert new_text
#+end_example

There is also =<C-@>= to insert the last inserted text and stop the insert mode.

:PROPERTIES:
:CUSTOM_ID: insert-mode-autocompletion

Completion shortcuts for the insert mode:
- =<C-N>= / =<C-P>= - generic completion, [[https://vimhelp.org/insert.txt.html#compl-generic][:h i_CTRL-N]]
- =<C-X><C-O>= - omni-completion, :h compl-omni
- =<C-X><C-L>= - lines

* Insert mode: complete whole lines
:PROPERTIES:
:CUSTOM_ID: insert-mode-complete-whole-lines
:END:

Complete whole lines with =<C-X><C-L>=:

- type some text, do =<C-X><C-L>=
- if there are a few suggestions - type a bit more and =<C-L>=
- now you are at the end of the line, and complete mode is still active
- press =<C-X><C-L>= a few more times to get more lines which follow the
  line you've got

See also: [[https://www.youtube.com/watch?v=3TX3kV3TICU][Let Vim Do the Typing]].

Similarly it is possible to complete sentences word-by-word with =<C-X><C-P>=.

* Command line window
:PROPERTIES:
:CUSTOM_ID: command-line-window
:END:

The command line window is a larger view of the command line.

It is very useful to edit long commands, or search patterns because we can use the normal
mode for editing (the normal command line, =:= only has insert mode).

- =q:= - opens a command-line window.
- =q/= - opens a search history window.

From the command line / search prompt - press =<C-F>= to switch to the
command-line window.

So don't re-map the =q:=! (as people often map it to =nop= because they accidentally
open the command line window meaning to do =:q=).

If you often invoke it accidentally, you probably have a problem with
entering =:q= correctly. In this case either remap the =:q= to
something else (for example, to =<Leader>q=) or type it like this:
- left pinky - =Shift=
- right pinky - =:=
- left pinky - =q=
(there is no chance to type it backwards this way).

* Visual mode
:PROPERTIES:
:CUSTOM_ID: visual-mode
:END:

In normal mode =v=, =V=, =<C-V>= start the char-, line-, block-wise visual mode.
Same keys in visual mode switch between char/line/block modes.

In normal mode =gv= re-selects the last visual selection (very useful).

In visual mode:

- =o= - move to other end of the selection (also very useful when you need to adjust
  the selection on the other end of the visual block)
- =gv= - switch current and previous visual selection
- =c= - change the selection (can re-paste after the change with
  =<C-R>"=, convenient for wrapping)
- =d= - delete the selection
- =r= - replace each character in the selection with entered character

In the visual block mode:

- =O= - move to other corner on the same line
- =$= - select until the end of line, will work for all lines even if the length is different
- =A= / =I= - append / prepend the block with entered text

Visual block + $ - selects a non-rectangular block. Then use =A= to append to the end of lines.
This is a very handy operation that often saves a lot of time.

Alternative: do =A= on one line, then select a block and repeat with =:'<,'>normal .=.

Select function body (between { and }): =vaBV= - select "a block" and
then change the selection mode to line-wise. To select 2 levels up -
=v2aBV= (when inside other {} block inside function) or =vaBaB= (repeat
=aB= to move to the next block). A mapping to work from any level inside
the function: =:map t ? function <CR>f{vaBV= (search backwards for
=function=, move to the ={= and then do =vaBV=).

* Calculator: expression register
:PROPERTIES:
:CUSTOM_ID: calculator-expression-register
:END:
In insert mode, =Ctrl-R== will prompt for the expression and insert the
result into the document.

It can also be convenient to have the expression in the document, then
copy it and insert when prompted. The insert operation will be in
command-line mode and we can do it using =Ctrl-R"= (in cmd mode, Ctrl-R
inserts the given register value).

For example:

#+begin_example
Document:
5+5*2       | ^ v $ y       - go to start, select until end, copy
5+5*2=      | A = Ctrl-R =  - append, enter =, Ctrl-R = to invoke prompt

Command line:
=           | Ctrl-R "      - insert the copied expression
=5+5*2      | Enter

Document:
5+5*2=15

cos(1.57)=7.963267e-4
#+end_example

See =:help i_CTRL-R_==, =:help c_CTRL-R=, =:help registers=.

* Manage Files
:PROPERTIES:
:CUSTOM_ID: manage-files
:END:

Some commands to manage files from Vim command line:

- =set path=.,**= - set path to recursively look through the sub-directories.
- =:find **/filename= or =:e **/filename= - search for the file and open it.
- =:find **/filename<TAB>= - display the list of matching files and move through them
- =:saveas new_name= - make a copy with =new_name= and switch to that copy
- =:saveas Ctrl-R %= - will insert the current file name, useful if new
  file name is similar to the current file name (also the following can
  be useful to edit the new name in the command-line window)
- =:w new_name= - make a copy, but don't switch to it
- =:drop file_name= - open file or jump to already opened version
- =:set switchbuf += useopen= + =:sbuffer path/to/file= - with [[https://vimhelp.org/options.txt.html#%27switchbuf%27]['useopen']]
  option will also search for already open buffer and jump to it (also
  affects quickfix)
- =:hardcopy= - print the file

The [[https://github.com/tpope/vim-eunuch]['tpope/vim-eunuch']] adds more commands to manage files (like Remove, Move, Chmod, Find,
SudoWrite, and others).

* Netrw
:PROPERTIES:
:CUSTOM_ID: netrw
:END:

Netrw is the standard Vim file manager:

- =<F1>= - open netrw help (use =<C-^>= to get back)
- =-= - go to the parent dir, =<CR>= - open a file
- =R= - rename file
- =d= - create dir
- =mf= - mark file, =mF= - unmark file, =mu= - unmark all files, =qF= -
  mark quickfix files
- =:MF pattern= - mark files by pattern, =mr= - query for pattern and
  mark files
- =mt= - mark target dir (or =:MP dir=), mark files, =mc= - copy files
  (=mm= - move)
- =mg= - vimgrep marked, =mz= - compress / decompress, =mx= - apply
  shell command, =md= - diff, =mp= - print
- =qf= - file info
- =<del>=, =D= - delete file or dir (marked files if there are any,
  visual selection if any)
- =gh= - hide / unhide dot files
- =i= - switch view mode (thin / long / wide / tree)
- =s= - sorting style
- =p= - preview the file
- =x= - view the file with an associated program (=gx= in any buffer)
- =X= - execute the file
- =mb= - bookmark the directory, =gb= - go to bookmarked dir, =qb= -
  list bookmarks and history
- =:Ex */pattern= - search in current dir
- =:Ex **/pattern= - search in current dir and sub-directories
- =:Ex **//pattern= - search in dir and sub-dirs inside files with vimgrep
